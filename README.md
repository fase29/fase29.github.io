# fase29.github.io

Personal page of Fabio Venturi: landing page, online CV (`/myCV/`) and privacy notice,
built with [Hugo](https://gohugo.io) and deployed to GitHub Pages by
`.github/workflows/hugo.yml` on every push to `master`.

- Links on the main page: `[[params.links]]` in `hugo.toml`
- CV content: `data/cv.yaml`
- Privacy notice: `content/privacy/index.md`

Preview locally with `hugo server` and open http://localhost:1313.

The blog lives in its own repo: [fase29/DevOpsOdyssey](https://github.com/fase29/DevOpsOdyssey).
